# AI Usage Disclosure — ASTRA INTEL

> This document discloses the use of AI tools during the development of ASTRA INTEL, in accordance with competition/submission transparency requirements.

### AI Tools Used

The following AI-assisted development tools were used during the development of ASTRA INTEL:

* **ChatGPT** — Used for debugging, understanding concepts and APIs, generating code suggestions, and preparing documentation.
* **Claude** — Used for code analysis, debugging, understanding project architecture, and improving implementation ideas.
* **Antigravity IDE** — Used for code completion, code suggestions, and accelerating development.

### Areas of Usage

* **Debugging:** Identifying errors and suggesting possible fixes.
* **Understanding APIs:** Understanding API functionality, parameters, and integration.
* **Code Suggestions:** Generating and improving code snippets during development.
* **Documentation:** Preparing technical documentation and explaining system components.

AI tools were used as development assistants, while the system architecture, implementation, testing, and final integration were reviewed and validated by the project team.




## Responsible Use Notes

- The LLM used at runtime operates under a strict grounding constraint: it answers using only the provided document excerpts and replies with a clear rejection if the answer is not found.
- No training data, fine-tuning, or model customisation was performed.
- No personal or sensitive user data was sent to any external service during development.
